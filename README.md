# Forest Escape — Interactive Fiction (Inform 7)

This project is an interactive fiction game implemented in Inform 7 as part of the Declarative Programming course.

The game combines narrative exploration, resource management, and rule-based mechanics such as health, hunger, inventory weight, time-based events, scenes, and multiple endings.
Player choices directly affect the story outcome, score, and relationship with a rideable pet.

## Features:

* Declarative rule-based game logic (Inform 7)
* Multiple rooms, regions, doors, and traps
* Health, hunger, scoring, and ranking system
* Time-dependent scenes and delayed events
* Inventory weight and carry-limit system
* Rideable pet with relationship mechanics
* Multiple endings based on player decisions

## Technologies:

* Inform 7
* Rideable Vehicles extension

## How to Play:

* Run the project in Inform 7 and play using standard text commands (e.g. look, go north, take, eat, ride, status).
